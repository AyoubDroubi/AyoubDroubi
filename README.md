## Selected engineering work

### Enterprise Document Management & Workflow Platform
A **9-service microservices platform** for document lifecycle management, correspondence routing, multi-level approvals, realtime collaboration, full-text search with Elasticsearch + OCR, and multi-tenant workspace isolation. I contribute as a primary engineer on one of the development tracks.

**Stack:** .NET 8 · ASP.NET Core · EF Core · MassTransit · RabbitMQ · Ocelot · OpenIddict · Redis · Elasticsearch · Hangfire · SignalR · Angular 17 · SQL Server / Oracle / PostgreSQL

[Project overview →](https://aldroubi.work/projects/enterprise-doc-workflow-platform)

### Municipal Fee Collection & Property Management System
Enterprise municipal platform covering property registration, commercial activity licensing, a **formula-driven dynamic fee engine**, invoicing, installments, payment allocation, exemption rules, and revenue reporting. I have been a core developer on the system from inception.

**Stack:** .NET 9 · EF Core 9 · MediatR · MassTransit · RabbitMQ · Redis · Hangfire · Angular 20 · NgRx · SQL Server / Oracle / PostgreSQL

[Project overview →](https://aldroubi.work/projects/municipal-fee-collection)

### DevOrchestra
A cross-platform **AI-augmented developer productivity platform** built around a Git-versioned knowledge vault and an MCP server, designed to give coding agents durable, semantically searchable project context with token-cost awareness.

**Stack:** .NET 10 · Blazor · C# · PostgreSQL · Redis · MCP · Clean Architecture · DDD · CQRS

[Project overview →](https://aldroubi.work/projects/dev-orchestra)
